# CineSearch

A platform where anyone may find information about their favorite movies.

## Features
- Search movies by title (OMDb)
- View detailed movie pages (poster, rating, runtime, cast, plot)
- Save/remove favorites
- Recent searches list
- Responsive UI with smooth animations

## Tech Stack
- React (Vite)
- TypeScript
- Tailwind CSS
- Framer Motion
- Redux Toolkit
- React Router

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file in the project root:

```
VITE_API_KEY=your_omdb_api_key
```
